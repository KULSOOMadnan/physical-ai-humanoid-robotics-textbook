# Getting Started with Physical AI & Humanoid Robotics

Welcome to the Physical AI & Humanoid Robotics Textbook! This guide will help you get started with the fundamental concepts and practical implementations of embodied artificial intelligence.

## Before You Begin

To make the most of this textbook, you should have:

- Basic programming knowledge (Python recommended)
- Understanding of fundamental mathematics (linear algebra, calculus)
- Familiarity with robotics concepts (optional but helpful)

## How to Use This Textbook

This textbook is organized into four comprehensive modules, each building upon the previous one:

1. **Module 1**: The Robotic Nervous System (ROS 2) - Establishes the foundation with ROS 2 concepts
2. **Module 2**: The Digital Twin (Gazebo & Unity) - Focuses on simulation environments
3. **Module 3**: The AI-Robot Brain (NVIDIA Isaac™) - Covers perception and control systems
4. **Module 4**: Vision-Language-Action (VLA) - Integrates all concepts in advanced applications

## Recommended Learning Path

We recommend following the modules in sequence for the best learning experience:

[Start with Module 1: The Robotic Nervous System (ROS 2)](./module1-ros2/chapter01/)

Or explore the modules individually based on your interests and needs using the sidebar navigation.

## Technical Requirements

- Computer with sufficient processing power for robotics simulation
- Python 3.8+ environment
- Access to robotics simulation tools (Gazebo, Unity, NVIDIA Isaac Sim)

## Need Help?

If you encounter any issues or have questions:

- Check the relevant module documentation
- Refer to the exercises and examples provided
- Join our community discussions (if available)
